# Assegai Common 0.10.1

Common 0.10.1 establishes one shared queue job and delivery-result contract for the first-party queue stack.

## What changed

- added `QueueJobCodecInterface` and the versioned `JsonQueueJobCodec`
- added processor callback type discovery through `QueueJobTypeResolver`
- added reflection-based hydration for readonly constructor DTOs, inherited private state, nested and intersection-typed objects, enums, dates, arrays, nullable values, and legacy JSON payloads
- added the canonical `QueueProcessResult`, which retains the hydrated job for successful and failed delivery attempts
- clarified that one `QueueInterface::process()` call handles at most one delivery, invokes the callback with a hydrated object, captures `Throwable`, and settles only after the callback outcome

## Compatibility and safety

- legacy JSON objects without an Assegai envelope are hydrated when the processor declares a concrete class, while declared array fields retain their nested array shape
- untyped `object` processors receive `stdClass`; envelope class metadata is not instantiated for an untyped processor
- envelope classes must be compatible with the processor's declared class or interface
- custom transports may inject another `QueueJobCodecInterface` implementation when reflection-based JSON hydration is not appropriate

## Coordinated rollout

Release Common 0.10.1 before Console 0.10.3, RabbitMQ 1.1.1, and Beanstalkd 1.1.1. Those releases depend on this queue contract.
