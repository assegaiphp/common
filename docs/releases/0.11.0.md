# Assegai Common 0.11.0

Common joins the coordinated AssegaiPHP 0.11 framework line. Its existing HTTP,
logging and queue contracts remain unchanged.

The compatible Attributes dependency now requires `~1.0.3`; older Attributes
patch versions are outside this release's supported baseline. Attributes retains
its established version stream.

Upgrade Common with the other installed 0.11 framework modules. Queue consumers
use the mapped RabbitMQ or Beanstalkd 1.2 line with Common `~0.11.0`. Publish the
required packages before activating these constraints in deployed applications.
