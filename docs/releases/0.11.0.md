# Assegai Common 0.11.0

Common joins the coordinated AssegaiPHP 0.11 framework line. Its existing HTTP,
logging and queue contracts remain unchanged.

Attributes retains the existing `^1.0` compatibility requirement and its
established version stream. The coordinated new-install recommendation remains
`~1.0.3`; that recommendation does not remove the consumer's existing support.
The repository lock refreshes affected HTTP dependencies within their existing
requirements.

Upgrade Common with the other installed 0.11 framework modules. Queue consumers
use the mapped RabbitMQ or Beanstalkd 1.2 line with Common `~0.11.0` for the
coordinated installation. The adapters retain verified Common 0.10.1 support
alongside the new line. Publish the required packages before activating the
new-install recommendations in deployed applications.
